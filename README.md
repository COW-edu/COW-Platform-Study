# COW Platform Study

COW-edu 플랫폼팀 양성 프로젝트 스터디 기록 레포입니다.
학기별 폴더 안에 주차별로 학습 내용을 정리합니다.

## 폴더 구조

```
COW-Platform-Study/
├── 2026-2/
│   ├── week1/
│   ├── week2/
│   └── ...
├── 2027-1/
│   └── ...
└── README.md
```

## 작성 방법

- 학기 시작 시 `연도-학기` 형식의 폴더를 새로 생성합니다. (예: `2026-2`)
- 학기 폴더 안에 주차별로 `week1`, `week2` ... 폴더를 생성합니다.
- 각 주차 폴더 안에 이름 또는 주제별로 md 파일을 작성합니다.
