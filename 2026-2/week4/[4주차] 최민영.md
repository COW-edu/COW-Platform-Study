## html과 css를 통해 Todo list 만들기
- Html 시맨틱 태그로 먼저 <nav class="sidebar">와 <header> <main>으로 구별한 후 작업하였다.
- Flexbox로 사이드바와 콘텐츠, 버튼과 텍스트 정렬하였다.
- CSS position fixed / absolute / relative를 이용하여 위치를 제어하였다.
- 스크롤 처리는 overflow-y:auto; 로 <main>만 스크롤 가능하게 처리하였다.
- 상태에 따른 스타일 구현을 위해 hover나 :checked / :has{}로 체크박스 상태를 표시하였다.
- Todo 카드를 반복 가능하게끔 동일한 HTML 구조를 만들어 Todo list를 작성하였다.

## 아쉬운 점 및 알게 된 점
- 데스크탑 디자인만 바탕으로 설계해 보아서 추후에 모바일까지 대응 가능하게끔 반응형으로 개발할 수 있으면 좋겠다.
- 맨 처음 구조 짜는 것부터 끝까지 해 보면서 ai의 도움도 받았지만 끝까지 완성해 본 것에 흥미를 느꼈다.
- 실제 웹 서비스들은 실무적으로 어떻게 폴더 정리를 하고 html, css 작업 순서가 어떻게 되는지 궁금하였다.
- 디자인적인 영역이지만 휴지통을 눌렀을 떄나 수정 및 삭제 버튼 등 사용자가 특정 행동을 취했을 때 다음 화면도 구현해서 발전시키는 과정이 필요하다는 걸 꺠달았다.

## 해커톤 하면서 알게 된 점 및 느낀 점
- 주제인 ai와 K-contetnts를 가지고 서비스를 제작하면서 가장 중요한 것은 기획력이라는 것을 꺠달았다.
- 무박 2일 즉 20시부터 다음날 9시까지의 시간 동안 하나의 앱 또는 웹을 만드는 과정에 있어서 주제의식을 계속 상기시키는 것이 중요하였다.
- 이제 html, css를 조금씩 공부해 나가는 입장에서 중간에 릴스 만들 떄 프론트엔드에 문제가 발생하였을 떄 적절한 대처를 하지 못한 것에 대한 아쉬움이 있었다.
- 언제나 느끼는 거지만 협업을 할 떄에는 소통이 중요하기에 자신의 분야 뿐만 아니라 다른 분야에 대한 기초 지식도 필요하다는 것을 절실히 깨달았다.
- ai 덕분에 무박 2일로 서비스를 만들어 본 경험이 자산이 되어 뜻깊은 시간이었다.
