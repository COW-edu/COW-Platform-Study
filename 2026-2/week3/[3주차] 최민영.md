# 추가 공부 내용 정리
- 참고자료: [CSS grid 정리 영상](https://www.youtube.com/watch?v=nxi1EXmPHRs)
- 아이템을 자유자재로 배치할 수 있는 CSS Layout에서는 flex와 grid가 있다.
- 한 줄에 꽉 채워진 <div> 요소들을 flex로 묶어주기만 해도 한 줄에 나란히 표현할 수 있다.
- flex : row(가로) / column(세로) 1차원적으로 표현 가능 +wrap 기능 사용하면 한 줄에 아이템이 꽉 찬 경우 다음 줄로 요소가 넘어가는 기능 존재(통상적으로 많이 사용)
- grid : row와 column 2차원적으로 표현 가능
### grid
#### 부모 컨테이너 grid
- display: grid = 전체적인 그리드의 모양과 사이즈 지정 가능
- grid-template-columns & grid-template-rows & grid-template-areas & grid gap(grid column gap& grid row gap)
#### 자식 요소 grid cell
- 얼마만큼의 크기 차지 & 그리드 안에서도 몇 개의 셀, 어떤 셀에 들어가길 원하는지
- grid-column-start & grid-column-end & grid-row-start & grid-row-end & grid area
.item.color{Item$}*10
- 기본적으로 <div>는 block 요소라 한 줄에 하나씩 나타난다.
- 반복적인 숫자로 넣을 때는 100px 100px 100px 100px 100px 이런 식이 아니라 repeat(반복 횟수, 수치) 함수를 사용한다. ex) repeat(2, 100px)
- fr = 화면을 나눠서 배율 개념으로 아이템을 분배한다. % px
- grid-column: 2 / -1;
