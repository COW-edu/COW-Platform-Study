## 📒 학습 기록 작성 방식

1. `COW-Platform-Study` 리포지토리를 본인의 GitHub 계정으로 Fork합니다.
2. Fork한 본인의 `COW-Platform-Study` 리포지토리를 Clone합니다.
3. `week{n}` 폴더 안에 `[n주차] {본인 이름}.md` 형식으로 파일을 작성합니다.
4. 매주 정해진 기한까지 Pull Request로 제출합니다.
    - PR 제목: `[N주차] {본인 이름} 학습 PR 제출합니다.`
